# Execution playbook: `prototype@1`

## Accepted brief form

This contract accepts `recon` only.

## Required sequence

1. State the decision question, authorized scope, and recorded timebox.
2. Gather references and define the alternatives to observe.
3. Build any experiment as explicit throwaway work in scratch space.
4. Record observations from the relevant surface and compare the alternatives.
5. End with a cited decision and recommendation; code does not survive without explicit later promotion.

## Required evidence

- Decision question and authorized scope.
- Alternatives explored and references used.
- Timebox recorded with start and end or an explicit exhaustion result.
- Surface observations and comparison.
- Cited decision and explicit throwaway declaration for prototype code.

## Exit predicate

The recon report contains an evidence-backed decision, and no prototype code survives unless a later explicit promotion creates a separate implementation task.

## Stop conditions

Stop and route to `feature@1` when there is no decision to make, or stop when the timebox is exhausted without enough evidence for a decision.

## Anti-patterns

Do not ship prototype code as an implementation.
Do not turn a decision recon into a strike.
Do not create playbook-owned review, delivery, approval, or terminal authority.
